# OtherApps

Маленький магазин Android-приложений **cleveroze** в бежево-ванильном Material You.
Каталог собирается из GitHub: репозитории, описания, иконки и APK из Releases.
ПК-программы (Stride, Potable и другие) в каталог не попадают.

<img src="art/app-icon.png" width="120" alt="OtherApps icon">

## Что умеет

- **Каталог из GitHub** — при запуске читает `github.com/cleveroze`, оставляет репозитории,
  у которых в релизах есть `.apk`, и подтягивает версию, размер, changelog и число загрузок.
  Без сети показывает сохранённый каталог.
- **Иконки из репозиториев** — логотипы приложений лежат в `assets/icons` и в vector drawable,
  сгенерированных из иконок проектов. Для новых проектов — монограмма.
- **Описания** — у каждого приложения есть теглайн, описание, список фич и changelog.
- **Скачивание APK** — напрямую из GitHub Releases с прогрессом, сохранением файла
  и запуском системного установщика (FileProvider + `REQUEST_INSTALL_PACKAGES`).
- **Загрузки** — история скачанных APK, повторная установка и удаление.
- **Анимации** — splash с облаком, поочерёдное появление карточек, пружинные нажатия,
  параллакс-облака, анимированный прогресс, переходы между экранами.
- **Material You** — тёплая бежевая палитра, крупные скругления, светлая и тёмная темы.

## Сборка

```bash
./gradlew :app:assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk` (подписан debug-ключом, ставится на телефон).

Нужны JDK 17+ и Android SDK 36.

## Структура

| Файл | Что внутри |
|---|---|
| `data/Catalog.kt` | ручные описания, фичи, иконки и резервные релизы |
| `data/StoreRepository.kt` | GitHub API, фильтр APK/ПК, кэш каталога |
| `data/ApkRepository.kt` | загрузка APK, прогресс, установка, хранение |
| `ui/HomeScreen.kt` | каталог, hero, поиск, категории |
| `ui/DetailScreen.kt` | карточка приложения и загрузка |
| `ui/DownloadsScreen.kt` | скачанные APK |
| `ui/AboutScreen.kt` | о проекте и ссылки |
| `ui/theme/Theme.kt` | бежевая Material You тема |

## Лицензия

Личный проект cleveroze. Иконки приложений принадлежат их проектам.
